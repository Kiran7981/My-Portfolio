# Cozydiadora Portfolio

A frontend-only product designer portfolio built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The portrait is loaded from Unsplash. Update the profile copy and contact email in `src/App.tsx` to personalize the page.
